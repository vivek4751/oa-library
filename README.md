# OA Library

A static question practice website with company browsing, assessment dates, coding solutions, MCQs, bookmarks, and solved tracking.

## Deploy on Vercel

Import this GitHub repository into Vercel. Select Framework Preset: Other, Root Directory: repository root, no build command, and Output Directory: public. No environment variables are required.

## Update

Replace public/index.html with the latest generated oa-library.html and push to the production branch. Vercel deploys connected Git pushes automatically. Local exports are not uploaded until committed and pushed.

Bookmarks and solved status are stored in each visitor's browser. No login or server is needed. Missing question content and image files remain unavailable.
